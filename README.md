# 棒人間💩うんち大避けゲーム v10

## v10.0
- v7を見た目・背景・ゲーム画面の基準として維持
- 朝→昼→夜の背景サイクル、太陽・月・星・丸い雲を維持
- 茶うんちは他の通常うんちと同じサイズ、炎なし。命中時は爆発してHP半減
- シルバーうんち：HP -15
- イカスミうんち：5秒間、画面上半分が黒くなり、落下うんちが見えにくくなる
- ハート：HP +10、大きなハート：HP +20。HPは100を超えて回復可能
- 大きなすっぽん：20秒無敵。出現率を大幅に低下
- マグネット：3秒間アイテムを引き寄せる
- トイレットペーパー：HPが減るうんちのダメージを5回無効。特殊効果は無効化しない
- レーザー銃：10発。タップした方向へ0.2秒レーザーを発射し、触れたうんちを消す
