# 棒人間💩うんち大避けゲーム

スマホ向けの棒人間うんち避けゲームです。

## 遊び方
- 画面をタップしたまま左右にスライドして棒人間を操作
- ピンクのうんち：HP -8
- 金のうんち：HP -20
- 緑のうんち：3秒間スピードダウン
- ハート：HP +10
- スッポン：10秒間無敵
- 便器：画面上のうんちを全消去
- スリッパ：5秒間スピードアップ
- HPが0になるまで、できるだけ長く生き残る

ハイスコアはブラウザのlocalStorageに保存されます。

## GitHub Pages
このリポジトリをGitHub Pagesで公開すると、`index.html` がそのままゲームとして表示されます。
