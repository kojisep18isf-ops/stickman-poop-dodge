# 棒人間💩うんち大避けゲーム

スマホ向けの棒人間うんち避けゲーム。GitHub Pagesで公開できます。

## 操作
画面をタップしたまま左右にスライドして棒人間を移動。

## うんち
- 🩷 ピンク：HP -8
- 🟡 金：HP -20
- 🟢 緑：3秒間スピードダウン
- 🟣 紫：5秒間、落下してくるうんちが1.5倍速

## アイテム
- ❤️ ハート：HP +10
- 🪠 スッポン：10秒間無敵
- 🚽 便器：画面上のうんちを全消去
- 🩴 スリッパ：5秒間スピードアップ

制限時間なし。HPが0になるまでの生存時間を競います。
ホーム画面にはベスト3を表示し、遊び方・アイテム説明画面があります。
ホーム画面とゲーム中で別のBGMを使用します。
