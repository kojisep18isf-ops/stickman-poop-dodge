# 棒人間💩うんち大避けゲーム v7

## v7.0
- ホーム画面のBEST 3をタップすると歴代BEST 10を表示
- ホーム右下に現在バージョン v7.0 を表示
- 大きなすっぽんの出現率を約70%減少
- 大きなハートの出現率を約10%減少
- うんち銃の出現率は変更なし
- 炎のうんちは他のうんちと同じサイズ。炎を後ろ、うんちを手前に描画
- アイテム類を従来より大きく表示
- うんち銃は10発。タップした位置への直線を画面外まで延長して0.2秒レーザー表示
- レーザーに触れたうんちは消滅
- BEST 3時代の保存データはBEST 10へ引き継ぎ
