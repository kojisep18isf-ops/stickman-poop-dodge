# 棒人間💩うんち大避けゲーム v9.0

GitHub Pages向けの1ファイル型ブラウザゲームです。

## v9.0の変更
- うんちの説明アイコンを実際のうんち形に修正。ピンク・茶・金・緑・紫・オレンジ・シルバー・イカスミを色分け。
- 炎のうんちを廃止し、特殊効果のない「茶うんち」に整理。
- ピンクうんち：HP -8、茶うんち：HP -8、金うんち：HP -20、シルバーうんち：HP -15。
- イカスミうんち：約5秒間、画面上部半分が黒くなり、落下うんちが見えにくくなる。
- 緑うんち：約3秒間、移動速度低下。紫うんち：約5秒間、落下速度1.5倍。オレンジうんち：1秒間その場で硬直。
- ハートはHP +10、大きなハートはHP +20。HPは100を超えて回復可能。
- 大きなすっぽんは20秒無敵のまま、出現率を大幅に低下。
- マグネット：3秒間アイテムを棒人間へ引き寄せる。
- トイレットペーパー：HPが減るうんちを5回まで無効化。特殊効果は防がない。
- レーザー銃：10発。タップ方向へ0.2秒レーザーを発射し、触れたうんちを消す。
- アイテムを全体的に少し大きく調整。
- BEST 3 / 歴代 BEST 10、昼夜サイクル、ゲームオーバー・リトライ等を維持。

## GitHub Pagesへの更新
`index.html` と `README.md` をリポジトリのファイルと置き換えてください。

ゲームURLはリポジトリのGitHub Pages URLをそのまま使用できます。
