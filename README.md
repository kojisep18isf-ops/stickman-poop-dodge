# 棒人間💩うんち大避けゲーム

GitHub Pages対応のスマホ向けゲームです。

## 操作
- 普段は画面をドラッグして左右移動
- うんち銃を取った後は、落ちてくるうんちをタップして撃ち落とす
- タップだけでは棒人間は移動しません

## うんち
- 🩷 ピンク：HP -8
- 🟡 金：HP -20
- 🟢 緑：3秒間スピードダウン
- 🟣 紫：5秒間、うんちが1.5倍速
- 🟠 オレンジ：触れると1秒間その場で硬直（HPダメージなし）

## アイテム
- ❤️ ハート：HP +10
- 💔 割れたハート：HP -5
- 🪠 スッポン：10秒間無敵
- 🪠✨ 大きなすっぽん：20秒間無敵
- 🚽 便器：画面上のうんちを全消去
- 🩴 スリッパ：5秒間スピードアップ
- 💗 大きなハート：HP +20
- 🔥💩 炎のうんち：HP半減
- 🔫 うんちの銃：拾うと10発。うんちをタップして撃ち落とす。弾切れで消える。

## 背景
朝→昼→夜を約30秒で1周するサイクル。太陽と月が時間経過に合わせて移動します。

ゲームオーバー画面からホーム画面へ戻ることができます。
