# 棒人間💩うんち大避けゲーム v10

## v10.0
- 以前のゲーム画面・朝昼晩の背景サイクル・太陽・月・星・雲などを維持。
- 茶うんちは他の通常うんちと同じサイズ。
- 茶うんちには炎を表示せず、当たると爆発してHPが半減。
- トイレットペーパー：HPが減るうんちのダメージを5回無効。緑・紫・オレンジ・イカスミなどの特殊効果は無効化しない。
- マグネット：3秒間、画面上のアイテムを棒人間へ強く引き寄せる。
- レーザー銃：10発。タップ方向へ画面外まで伸びるレーザーを0.2秒表示し、レーザーに触れたうんちを消す。
- 遊び方画面を「うんちの種類」「回復・有利なアイテム」「マイナスに働くアイテム」に整理。
- うんちの説明アイコンを色付きのうんち形に修正。
- ホーム画面下部のバージョン表示が見切れにくいよう修正。
- ゲーム中に一時停止・再開できるボタンを追加。
- ブラウザをバックグラウンドにしたときはゲーム時間・ゲーム進行が進まないよう修正。復帰すると続きから再開。
- HPは100を超えて回復可能。
- 大きなすっぽんは20秒無敵で、出現率を低く設定。

GitHub Pagesでは `index.html` と `README.md` を置き換えてください。
