# 棒人間💩うんち大避けゲーム

GitHub Pages対応のスマホ向けゲームです。

## 操作
画面をタップしたまま左右にスライドして棒人間を移動します。

## 落下物
- 🩷 3段のピンクうんち：HP -8
- 🟡 3段の金のうんち：HP -20
- 🟢 3段の緑のうんち：3秒間スピードダウン
- ❤️ ハート：HP +10
- 🪠 スッポン：10秒間無敵
- 🚽 便器：画面上のうんちを全消去
- 🩴 スリッパ：5秒間スピードアップ

制限時間はなく、HPが0になるまでの生存時間をハイスコアとして記録します。

## BGM
ホーム画面とゲーム中で別の自動生成BGMを使用しています。
